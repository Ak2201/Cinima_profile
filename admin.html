Connect to GitHub

Publishing saves your changes to the portfolio's GitHub repository, and GitHub Pages puts them live. Only someone with write access to the repository can publish.

How do I get a token? (2 minutes)
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: “Only select repositories” → pick your portfolio repo.
  3. Permissions: Contents → Read and write. Optionally Pages → Read (to show deploy status).
  4. Set an expiry (e.g. 90 days), generate, and paste it above.

The token is only sent to api.github.com. It's kept in this browser tab, or on this device if you tick “Remember”.
